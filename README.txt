साथ चले हम FOUNDATION - Free NGO Website

फाइलें:
- index.html : मुख्य वेबसाइट
- style.css  : डिजाइन और responsive layout
- script.js  : mobile menu, year और contact form
- assets/logo.jpg : आपके द्वारा दिया गया NGO logo

चलाने का तरीका:
1. सभी फाइलें एक ही folder में रखें।
2. index.html पर double-click करके browser में खोलें।
3. Free hosting पर upload करने के लिए पूरे folder की files upload करें।

महत्वपूर्ण:
- फोन, ईमेल, पता, UPI और बैंक विवरण अभी demo हैं। इन्हें अपनी वास्तविक जानकारी से बदलें।
- Contact form अभी demo alert दिखाता है; वास्तविक submissions के लिए Formspree, Google Forms या backend जोड़ा जा सकता है।
